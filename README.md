# DNA-sequence-classification-using-transformer-model-virus-BERT-
DNA sequence classification using VirusBERT uses a Transformer model to identify viruses from genome sequences. DNA is converted into 3-mer tokens and processed using embeddings and multi-head attention. CNN layers detect local patterns, and Softmax classifies viruses such as SARS-CoV-2, MERS, Ebola, Dengue, and Influenza.
